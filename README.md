# KNOCK KNOCK / The Unknown Box

> 看不见它，但它会回应。
>
> 敲两下，等一会儿，或靠近一点听。每一次轻微回应，都会留下一点线索。

KNOCK KNOCK 是一项关于照料、回应与想象的课程设计。我们尝试设计一个没有固定动物外形的陪伴机器人：用户不需要打开盒子确认里面是什么，而是在一次次相处中，通过光、声音、停顿和细微动作，慢慢形成自己的理解。

## 这项设计想问什么

我们从一个问题开始：当陪伴对象没有明确的动物外形时，人是否仍能通过照料、等待和回应，与它建立关系？

因此，盒子始终保留未知。它不突然露出宠物形象，也不把行为结论写成固定身份。用户能看到的是一次次相处留下的痕迹，以及一个会随着相处改变的暂时理解。

## 一次相处如何走完一圈

```text
发出邀请
敲两下、等待、轻触或倾听
        ↓
感到回应
光靠近或扩散，伴随克制的声音与细微动作
        ↓
留下线索
把光、声音、停留和重复互动记进证据册
        ↓
形成暂时理解
性格档案呈现可变化的行为倾向，不替盒子定种
        ↓
把关系带到盒群岛
盒子之间以匿名、异步的来访与声音明信片发生联系
        ↓
回到自己的盒子
新的线索影响下一次相处，循环继续
```

盒群岛的关系主体是盒子与盒子。页面中的来访和声音明信片用于演示这种关系；目前没有真实在线用户、云端消息或多人同步。

## 建议体验路线

1. 打开网页，先观察盒子在安静状态下缓慢变化的光场。
2. 试试「轻轻碰」或直接触摸盒面，留意光团如何靠近触点、聚焦，再慢慢散开。
3. 试试「敲两下」和「等一会儿」，感受回应之间的停顿，而不是只看一次亮度变化。
4. 在手机 App 原型中打开「记录」与「性格」，看看一次互动如何成为线索，而不是变成对盒子的确定判断。
5. 进入「盒群岛」，体验盒子之间的匿名来访与声音明信片，再回到自己的盒子。

## 从概念汇报到当前原型

课程中的早期概念汇报记录了项目起点，包括灯笼式外壳、宠物行为隐喻与 Stack-chan 的设想。当前网页原型则是后续收敛的结果：我们保留「不确定的陪伴」这个问题，把盒体改为一体成型的未知方盒，并用实时光场、声音和交互节奏表达回应。

所以早期汇报与网页中的造型不完全相同，代表的是概念演进的前后阶段，不是两个互相矛盾的最终方案。上一轮结题反馈与原型走查之后，我们进一步明确了体验入口、强化了光对动作的反馈，也梳理了手机滚动与盒子交互的边界。更多设计脉络见[项目故事](./docs/project-story.md)。

## 原型边界

这是用于课程展示与体验讨论的网页原型，不代表真实硬件已经制作完成。3D 盒子使用 Three.js 和 WebGL 实时渲染，声音由 Web Audio API 在浏览器中生成；相处记录与设置保存在当前浏览器的 `localStorage`。盒群岛来访是可重复体验的示例内容，没有接入真实用户或服务端。

## 本地运行

如果要查看源码或启动本地版本，需要安装 Node.js。只想体验作品时无需执行这些步骤。

```bash
npm ci
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

项目使用 Vite + React，构建输出目录为 `dist`。核心文件：

- `src/main.jsx`：Three.js 场景、GLSL 光场、交互与 App 原型。
- `src/lightPresets.js`：六种光场配色与参数预设。
- `src/styles.css`：页面、响应式布局与手机界面样式。
- `public/assets/`：品牌与贴纸素材。
- `docs/`：项目故事、交互、导航、声音和质量检查记录。

开发时在 URL 后添加 `?lightDebug=1`，可查看光场与 Raycaster 的调试信息。
