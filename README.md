# knock knock / The Unknown Box — Three.js prototype

这是一个从现有方案重新搭建的本地交互原型，不是静态展示页。

## 已实现

- Three.js 实体未知盒：圆润但不是巨型灯笼，包含盒体、盒盖、中心信号和低存在感的呼吸式运动。
- p5.js 固定笔触层：在 3D 舞台上叠加两层不完全重合的手绘框和回应记号，避免把“手绘感”只做成滤镜。
- D3.js 性格轨迹：将四个性格方向画成一条随行为变化的关系轨迹，而不是一组孤立进度条。
- 手绘手部素材：用作“人靠近但尚未触碰”的叙事层，强调照料动作。
- 点击／触摸盒体：触发“靠近 → 轻微回应”的反馈。
- `敲`：两下敲击的概念事件，等待 1.8 秒后回应。
- `等`：等待 2.4 秒后生成“等到它回答”的证据和徽章。
- `触摸`：生成触摸证据，改变回应参数。
- Web Audio API 合成的轻量敲击声与回应声，不依赖外部音频文件。
- 养成状态：bond、patience、expression、social，使用 localStorage 保存。
- 徽章：未知的开始、等到它回答、第三次来访、声音寄出去了。
- 四个 App 区域：我的盒子、盒群岛、证据册、性格档案。
- 展示板拆分为两个互不混淆的对象：左侧独立圆形实体场景，右侧 390 × 780 手机 App 原型。
- 盒群岛改用 `box-island.png` 贴纸式插画承载空间关系，手机内提供声音、来访、关系三类图标入口。
- 视觉素材仍使用橘红色、米白色、稚拙手绘贴纸语言。

## 本地启动

需要 Node.js 18+。

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## Vercel

这是标准 Vite 项目：Build Command 使用 `npm run build`，Output Directory 使用 `dist`。项目已设置 `base: './'`，静态资源可以在 Vercel 路径下正常使用。

## 设计与技术决策

- 养成规则与 Three.js 展示分离，先写入确定性状态，再由 3D 画面表达。
- 不做“宠物突然跳出来”的揭示；机器人反馈只通过中心光、延迟、声音和很小的姿态变化表达。
- 不把徽章做成金币式奖励；徽章记录关系证据，并改变后续的性格解释。
- 不复制任何开源项目素材。开源项目只作为架构与交互研究参考。
