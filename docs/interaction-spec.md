# KNOCK KNOCK · Interaction & Copy Notes

更新：2026-10-23

## 产品立场

KNOCK KNOCK 是一个没有固定动物外形的陪伴机器人原型。它住在一只一体成型、不可打开的圆角盒体中，以光、声音和细微动作回应照料。产品要验证“被回应”的感受，而不是猜中它是什么动物。

动物行为只可作为隐喻：猫的停顿、狗的主动回应、兔子的短暂靠近、小动物的细听，都不能成为盒内身份的确认。

主问题：**照料、回应与想象，是否足以建立情感关系？**

## 交互节奏

| 输入 | 意义 | 视觉回应 | 声音回应 | 文案方向 |
| --- | --- | --- | --- | --- |
| 敲两下 | 发出邀请 | 手指贴纸轻点两次；光先收一下，停顿后再浮现 | 两声轻、短、偏木质的合成叩响 | “两下轻敲，是一次邀请。” |
| 等一会儿 | 把时间留给它 | 沙漏贴纸轻轻摇两次；光缓慢游移，不强行立即作答 | 一次低音量、滤过高频的纸面窸窣 | “这一次，让它自己决定什么时候回答。” |
| 轻轻碰 | 接触与安抚 | 光靠近触点，核心较集中；随后停留并柔和扩散 | 更轻的双叩，音量低于敲击邀请 | “它先停一下，再慢慢靠近。” |
| 听听看 | 留意盒内活动 | 细小的光脉冲，不闪烁 | 低而柔的原创合成回响，不对应具体物种 | “听听细微的动静，也给沉默留一点位置。” |
| 离开 / 重逢 | 休息与再次相遇 | 光不立即复位；回来时缓慢醒来 | 默认保持安静，不连续播放提示音 | “它还记得刚才停留的地方。” |

声音全部由 Web Audio API 程序化合成，不包含第三方采样。可在设置关闭；未解锁音频的浏览器也不影响互动。

## 群岛来访

- 群岛是异步声音明信片，不是实时聊天或排行榜。
- “来访”打开独立的二级页面，展示匿名盒号、主人捎来的简短观察、抵达时间和一条声音/光线痕迹。
- 访客可试听含蓄的回响，并将明信片收进本地收藏；保存状态使用独立的 `localStorage` key，不覆盖既有相处记录。
- 当前来信为原型示例数据，页面文案不应声称已连接真实邻居或云端同步。

## 文案规则

- 具体描述日常动作和回应，不用开发术语或抽象状态词。
- 探索进度表示相处阶段；性格倾向表示证据支持度；二者不得混为一个指标。
- 性格猜测必须标为“暂时理解”，并允许随下一次互动变化。
- 纪念章记录一段相处，不是积分奖励。
- “盒内是什么”不揭晓，物种不确诊。

## 验收

- 开启/关闭声音分别点击四种动作，确认只播放对应反馈且音量温和。
- 等待时观察沙漏轻摆两次；系统减少动态效果时不摇晃。
- 触摸光点有清楚的聚焦核心，离开后柔和弥散；不出现大块硬边色斑或剧烈闪烁。
- 从群岛进入“来访”，试听、收藏、取消收藏，再切走并返回；收藏在本地保留。
- 键盘可打开来访页、触发试听/收藏，并返回地图。
