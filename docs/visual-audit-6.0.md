## 交互专项

- `今天 → 查看探索阶段`：打开纵向时间线；节点可点选阶段详情。
- `今天 → 性格卡片`：打开性格详情；只显示与当前倾向有关的线索。
- `今天 → 最近线索`：打开证据详情 Sheet。
- `群岛 → 听见`：打开声音明信片收件箱，不只播放后结束。
- `群岛 → 来访`：进入匿名访客列表；可试听、收藏和返回群岛。
- `群岛 → 来访 → 查看访客详情`：进入独立二级页；可听见、收进记录或暂不回应。
- `群岛 → 关系`：进入关系光痕页；不跳到性格页，也不形成排行榜。
- `群岛 → 寄出一段声音`：打开编辑器；发送后在本地状态中模拟延迟回信。
- `设置`：声音开关、性格档案入口和重新开始确认均有可见反馈。

## 中文文案审查清单

- [x] 核心句只保留一个带想象空间的表达。
- [x] “探索进度”与“性格倾向”分开解释。
- [x] 不使用 MBTI、物种鉴定、排行榜、金币、死亡惩罚或实时聊天措辞。
- [x] “没有回应”被表达为安静状态，不作为错误提示。
- [x] 演示访客、回信与本地状态明确标注为示例 / 模拟数据。
- [x] 按钮尽量使用动作动词：查看、听见、收进、寄出、返回、关闭。

## 尚未纳入本轮的风险

1. 线上部署版仍需要在合并本地最新修改后重新做一次 Vercel Preview 走查。
2. WebGL 在不同设备上的色彩与 GPU 兼容性仍需真实硬件复核；当前 Edge 截图已确认本地场景没有空白。
3. 声音是 Web Audio 程序化模拟，不代表真实录音或在线多人同步。
4. 当前仍保留既有单 chunk 体积提示（约 873 kB），不影响构建，但可作为后续性能优化项。
