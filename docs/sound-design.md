# KNOCK KNOCK 6.0 Sound Design

当前使用 Web Audio API 程序化合成，不依赖外部录音，也不模拟可识别的动物叫声。

| 事件 | 声音语言 | 视觉配合 |
| --- | --- | --- |
| 敲两下 | 两个柔和、偏空心的低音叩击 | 光先停顿，再缓慢回应 |
| 等一会儿 | 低音量纸面窸窣 | 沙漏短暂摇动，保持安静 |
| 轻轻碰 | 更软的双叩 | 光向触点靠近并停留 |
| 听听看 | 两个低音量、缓慢下沉的正弦音 | 波形与声音明信片出现 |
| 回应 | 温暖的短音 | `刚刚回应` 状态和线索记录 |
| 明信片 | 一枚短暂的声音标记 | 纸面预览、寄出状态、延迟回信 |

声音管理器复用同一 `AudioContext`，在用户首次交互后解锁；`soundEnabled` 为 false 时不触发音频节点。声音不可用时，光、文字和状态仍保持可用。

沉默是有效状态：没有新的回应时显示安静文案，不弹错误，也不催促用户签到。
