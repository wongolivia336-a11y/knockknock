# KNOCK KNOCK 6.0 App Navigation

## 一级导航

手机内只保留四个 Tab：

1. 今天：便签、当前探索、暂时性格猜测、最近线索。
2. 记录：证据筛选、收藏徽章、证据列表。
3. 群岛：地图、听见、来访、关系、寄出声音。
4. 性格：当前倾向、变化轨迹、纪念章和探索入口。

## 二级表面

- 探索阶段：纵向五节点时间线；节点点击后展示阶段详情和真实代表性证据。
- 证据详情：Bottom Sheet，显示类别、观察原因和支持的倾向。
- 性格详情：Bottom Sheet，只显示 `supports` 关联的线索；证据不足时显示开放状态。
- 听见：声音明信片收件箱；播放、延迟回信和本地演示说明都在同一表面完成。
- 来访：匿名示例来信列表；可以试听、收进明信片册和返回群岛。
- 关系：关系光痕页，不跳到性格页，不提供实时聊天或排行榜。
- 寄出声音：选择声音 → 纸面预览 → 发送确认 → 本地模拟延迟回信。
- 设置：声音开关、性格档案入口、重新开始确认。

所有二级表面均支持关闭、返回或 Escape 返回，不清除现有 localStorage 记录。
