# KNOCK KNOCK 6.0 Design System

## 基础

- 背景：`#f8f5f0`
- 纸张：`#fff9f2`
- 文字：`#302825`
- 次级文字：`#766962`
- 强调橘：`#f39b6b`
- 辅助色：奶油黄、低饱和紫、薄荷绿、雾蓝
- 页面左右留白：桌面 24–64px；手机框内部 16–20px
- 卡片圆角：12 / 18 / 24 / 32px

## 层级

- 页面标题：约 42–70px（响应式）
- 手机一级标题：26–28px
- 手机卡片标题：15–17px
- 正文：12–15px，行高约 1.45–1.65
- 辅助文字：9–11px，仅用于时间、状态和非关键标签

## 组件原则

- 功能图标使用统一 24 × 24 inline SVG，线宽约 1.7。
- 情绪图形使用独立 SVG / 透明贴纸，白边和阴影由 CSS 叠加。
- 主要信息使用纸张表面与留白组织，不为每一块内容添加阴影。
- Bottom Sheet 适用于证据、性格、探索、来信和明信片编辑；内部可滚动，最大高度不越出手机边界。
- 主要按钮最小高度约 40px；点击后必须有页面、Sheet、状态或声音反馈。

## 状态语言

`照料 → 回应 → 相处习惯 → 暂时理解`

探索进度描述相处阶段；性格数值只表示当前线索支持程度。它们不能互相替代，也不构成物种或人格测定。
